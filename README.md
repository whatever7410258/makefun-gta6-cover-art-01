Cover Snap — a GTA 6-style cover art maker. Turn your own photo and a caption into a multi-panel Vice City sunset poster with bold caption lettering, and export it as a PNG to share. Static files only, works fully offline in desktop Chrome; photos never leave your machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
